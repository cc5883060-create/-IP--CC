“轻奢感剪辑为什么叫轻奢？” 
“为什么不是奢侈？”
“不是高级？而是轻奢呢？”

因为轻奢是有调性的，跟奢侈品比起来，可能只是品牌价值赋能上的区别，导致价值差距会相差甚远，但品质甚至有可能高于奢侈品，所以正是因为这一点，轻奢品是可以服务于大众的！

最开始提出轻奢感剪辑的想法，其实就是想和市面上的高级感做区别，所谓的高级感就是各种剪辑技巧乱加一通，多就是好，其实真正的高级感是“大道至简”，而且轻奢感这个概念里不仅仅只有高级，还有他的品质、调性、设计理念，都突出了下面这五个字“简单且高级”！

总的来说，“轻奢感剪辑”就是具有普适性，大众可以接受的具有高级感审美的剪辑。
真正意义上去根据ip风格，内容方向，文字内核去做相对应的剪辑，像做艺术品一样去做短视频！
这样做出来的作品才会有轻奢感，才会有质感、有调性！
