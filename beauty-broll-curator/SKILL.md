# 美业 B-roll 选片师

把文案中的抽象观点转成能被镜头直接看见的动作、人物状态和环境证据。每一段都要让观众不读字幕也能大致理解观点。

## 先确认交付边界

从用户提供的 SRT、逐字稿或成片中提取：

- 每段起止时间、持续时长和中心观点。
- 画幅、最低分辨率、人物偏好、平台偏好、是否要求明星、是否需要下载。
- 已被用户认可的素材。后续修改只替换不合格项，除非用户明确要求全部重做。

缺少次要信息时按以下默认值执行：9:16、源画面至少 1080×1920、亚洲或中国面孔优先、单条素材覆盖整段、无压脸字幕和显著水印。

## 建立逐段视觉命题

对每段写一句“必须拍到什么”，再搜索素材。不要直接拿抽象关键词搜索。

- “气场柔和”转成自然微笑、放松下颌、稳定眼神和缓慢转身。
- “眉毛支撑精气神”转成眉眼极近景、顺毛流梳理或干净眉形。
- “体态是第二张脸”转成全身或至少膝上步态，能看见肩颈、下巴和脚步节奏。
- “穿搭做减法”转成合身廓形、干净配色和可辨认的面料细节。
- “远离消耗”转成离开嘈杂场景、整理空间、独处、进入开阔自然环境或专注完成一件事。

详细映射方式见 [references/semantic-matching.md](references/semantic-matching.md)。

## 搜索与选择

优先找创作者或品牌公开发布的原帖、官方活动视频、秀场母片及明确可复用的素材库。可搜索抖音、小红书、微信视频号、YouTube 和其他公开网页。

候选顺序：

1. 语义完全匹配，动作和构图能证明文案。
2. 清晰、稳定、可裁成 9:16，主体在安全区。
3. 无大字幕、贴纸或品牌字压住脸和关键动作。
4. 高级棚拍、真实秀场、公开活动或生活化电影感画面。
5. 用户要求多人物时，每段尽量用不同人物。

熟悉度不能替代匹配度。明星素材如果模糊、字幕压脸或动作不贴文案，应淘汰并说明原因。

搜索结果必须打开原帖核验，不根据标题、缩略图或搜索摘要直接交付。记录原帖 URL、发布者、平台、分辨率、时长及选用理由。

## 技术验收

下载或裁切前后都检查：

- 原始有效分辨率至少 1080p；人工放大不能算作达标。
- 竖屏优先 1080×1920 或更高。横屏素材只有在中心裁切仍保留完整动作时才使用。
- 快速检查开头、中段和结尾，排除空镜、切镜、人物离开画面、失焦和遮挡。
- 不把刻意运动模糊、低码率涂抹或过度锐化当成电影感。
- 裁切后不切断头顶、下巴、肩线、手部或文案所依赖的动作。
- 时长覆盖对应字幕段；短素材可轻微慢放，但避免肉眼可见卡顿。
- 输出 MP4/H.264/yuv420p，并使用可快速加载的文件头，确保剪映可直接导入。

可用 [scripts/inspect_media.py](scripts/inspect_media.py) 批量检查本地文件的分辨率、时长、帧率、画幅和编码。该脚本需要系统可调用 `ffprobe`。

完整人工复核表见 [references/quality-checklist.md](references/quality-checklist.md)。

## 下载与版权边界

只有公开可访问且允许直接取得的文件才下载。不要绕过登录、付费、DRM、防盗链或平台访问控制。无法可靠下载时交付具体原帖 URL，不用低清录屏替代。

公开发布不等于获得商业使用授权。来源清单应区分：

- 素材库许可内容：记录许可页面。
- 明星、秀场、广告、路人切片：标为“需发布者自行确认使用授权”。

不要把第三方视频文件提交到 Skill 仓库或公开 Git 仓库。

## 交付格式

需要下载时，为每段输出独立 MP4，文件名包含序号、观点、人物或画面和分辨率。另附 UTF-8 来源清单，至少包含：

| 字段 | 内容 |
|---|---|
| 段落 | 序号、字幕起止时间、持续时长 |
| 文案内核 | 一句话观点 |
| 画面证据 | 镜头中实际出现的动作或细节 |
| 文件规格 | 文件名、分辨率、帧率、时长 |
| 来源 | 原帖 URL、平台、发布者 |
| 授权备注 | 素材库许可或需另行确认 |

如果用户只要网址，仍需给出逐段对应理由、画质核验结果和备选链接；不要只交一串搜索结果。

## 迭代规则

收到“不贴切、太抽象、模糊、字幕压脸”等反馈时，把反馈转换成新的镜头条件，然后只重做失败项。每次替换都说明旧素材为何失败、新素材如何直接体现文案，并再次检查全段覆盖。
