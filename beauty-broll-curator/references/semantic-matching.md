# 文案到镜头的语义映射

## 判断原则

先找文案中的可观察变化，再确定景别和动作。一个候选镜头至少回答：观众具体看见了什么？这个动作或细节为什么能证明文案？只营造氛围、无法回答第二个问题的镜头属于弱匹配。

## 常见美业主题

| 文案主题 | 强匹配镜头 | 弱匹配或不匹配 |
|---|---|---|
| 气场、松弛感 | 自然微笑、稳定注视、放松肩颈、从容转身 | 随机慢动作、纯风景、过度摆拍大笑 |
| 眉形、眉眼支撑 | 眉眼极近景、顺毛流梳理、对称眉形 | 全身照、看不清眉毛的脸部远景 |
| 发质、颅顶 | 逆光发丝、梳发、自然蓬松头顶、转头展示光泽 | 只拍发型背面、明显假发或过度滤镜 |
| 体态、步态 | 正面或侧面全身走路，肩、颈、下巴、脚步同时可见 | 只拍脸、坐姿、快速混剪、空镜 |
| 皮肤状态 | 自然光面部近景、清洁保湿、防晒动作、真实肌理 | 过度磨皮、彩妆遮盖、无法看清皮肤 |
| 表情稳定 | 连续近景、眼神固定、面部放松、事件中保持从容 | 单张定格、夸张表演、频繁切镜 |
| 穿搭减法 | 全身或膝上造型、干净配色、廓形和面料特写 | 服装店空镜、杂乱印花、只拍配饰 |
| 环境与能量 | 离开人群、整理空间、独处阅读、森林呼吸、专注工作 | 无人物风景、玄学特效、抽象光影 |

## 搜索词结构

使用“人物 + 可见动作 + 场景或质感 + 技术条件”的组合，例如：

- `刘雯 + 正面走秀 + full show/runway + 4K`
- `亚洲女性 + eyebrow brushing close-up + vertical 4K`
- `中国女明星 + calm gaze studio + 无字幕/原片`

平台内搜索时补充活动、品牌、年份或官方账号；网页搜索时优先定位原帖而非聚合转载页。

## 连续覆盖

一个段落可使用一条完整镜头，也可使用 2–3 个镜头，但每个镜头都要服务同一命题。若文案包含并列动作，可按动作顺序切换。例如“肩打开、下巴微收、脚踩实”可用正面中景、侧面上半身和全身步态三个连续镜头。
