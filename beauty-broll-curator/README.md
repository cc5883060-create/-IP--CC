# 美业 B-roll 选片师

一个面向美业、审美、形象管理和女性成长口播的 Codex Skill。它把 SRT 或逐字稿逐段转成可观察的镜头条件，筛选高清竖屏素材，并输出可直接导入剪映的 MP4 与来源清单。

## 安装

将仓库目录复制到 Codex Skills 目录：

```text
~/.codex/skills/beauty-broll-curator
```

重新启动 Codex 后，可以直接说：

```text
使用 $beauty-broll-curator 为这份美业口播或 SRT 匹配高清竖屏 B-roll。
```

仓库不包含任何第三方明星、秀场或广告视频。实际使用素材前，请根据来源和发布场景确认授权。
